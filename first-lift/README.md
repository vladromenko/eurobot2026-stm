# Стенд подъёмника Eurobot

Здесь сохранены изменения из каталога робота `~/test_stepper/first-lift`. Исходная ревизия прошивки — `0d073ce`. Три патча применяются последовательно. Первый восстанавливает раннюю прошивку с ручным управлением подъёмником, второй добавляет выдержку времени CS и проверку состояния L6474, третий переносит подъёмник и диагностику на Stepper Output 3. В обеих диагностических версиях сервы назначены на PWM5 и PWM6. Интерфейс пульта использует историческое имя Lift2.

## Воспроизведение сборок

На роботе из корня этого репозитория выполните:

```bash
./first-lift/build-images.sh
```

Скрипт извлекает исходники из Git во временный каталог, собирает три версии с пресетом `bench` и сверяет каждый HEX с контрольной суммой фактической сборки на роботе. После успешной проверки образы находятся рядом с этим файлом. Для точного воспроизведения требуется та же цепочка компилятора и binutils, что на роботе. Сборка выполняется без доступа к плате.

## Установка и диагностика

На стенде использовались `install-stepper2-check.sh` и `install-stepper3-check.sh`. Каждый скрипт записывает соответствующий HEX, запускает контроллер и читает регистры драйверов. Для диагностических скриптов требуется `panel/.venv/bin/python` с pyserial. На роботе это окружение доступно через ссылку на `~/test_low_2026_final/.venv`. Пульт запускается через `panel/start.sh`.

Последние попытки ARM вернули код 5 и статус L6474 `0xEE13`. Команд движения в этих сеансах не было. Журнал ARM сам по себе не идентифицирует физический канал.

В отдельном сеансе `mechanism_console.py` на Stepper 2 до команды движения вернул статус `0xFE13` без ошибок при `TVAL=0x0F` (уставка около 500 мА). После `stepper + 32` получены `0xEE13`, `OCD`, `HiZ=True` и выключенный выход STEP (`TIM1_CCER=0`). Причина срабатывания защиты осталась открытой. В том же снимке оба канала TIM5 были выключены, оба регистра CCR равнялись нулю. Измерений напряжения питания или сигнала на разъёмах PWM5/PWM6 в этом сеансе нет. Работа обоих сервоприводов и движение на Stepper 3 остались неподтверждёнными.

## Восстановление

`restore-original.sh --check-only` останавливает ядро, читает флеш и показывает отличающиеся секторы. `restore-original.sh` записывает отличающиеся секторы и побайтно проверяет весь 1 МиБ. После восстановления ядро остаётся остановленным.

Скрипт использует полный исходный дамп `~/stm32_backups/stm32-before-bench-free-20261120-235556.bin` на роботе. Его контрольная сумма записана в скрипте. Откат на стенде завершился совпадением всего образа.

После отката для обычного управления используется `~/test_low_2026_final/start.sh`. Штатный и стендовый пульты при запуске проверяют связь командами `PING` и `GET_SPEED`. Стендовый `panel/start.sh` затем дополнительно отправляет `Lift2 OFF`. После восстановления оператор получил ответ на проверку связи. Версию записанного образа подтверждает побайтная сверка при откате.
